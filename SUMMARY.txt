🚀 COMO USAR
================================================================================

1. ATIVAR
   - Editar: deploy/.env
   - Alterar: DEBUG_SELECTOR_INTERACTIVE=true
   - Já está ativado!

2. EXECUTAR
   - python main.py

3. ACOMPANHAR
   - [SELECTOR] logs aparecem no console
   - Vê cada ação no navegador
   - Pressiona ENTER para continuar

4. SE FALHAR
   - Screenshots salvos automaticamente
   - HTML diagnostics salvos automaticamente
   - Verificar artifacts/screenshots/ e artifacts/diagnostics/

5. DESATIVAR (PRODUÇÃO)
   - Alterar: DEBUG_SELECTOR_INTERACTIVE=false
   - Continua sem pausas
